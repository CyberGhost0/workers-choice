Quick Setup

Get the full app running locally in minutes

1

Clone the repository

Download the code to your machine

git clone https://github.com/YOUR_USERNAME/workers-choice.git
2

Set up environment variables

Copy the example config and add your keys

cp .env.example .env
3

Start with Docker

Build and launch all 4 services

docker compose up -d
4

Run database migrations

Apply the schema to PostgreSQL

cd server && npx prisma migrate dev
5

Access the application

Open your browser and you're in

Frontend: http://localhost:3000  |  API: http://localhost:4000
